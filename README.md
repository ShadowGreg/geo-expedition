# ГеоЭкспедиция — первая версия

Семейная викторина для Android. APK: `dist/geo-expedition-v0.1.1.apk`, около 59 МБ. Android 6.0+, базовая версия проверена на эмуляторе Android 14. Release-сборка подписана тестовым Android Debug ключом для ручной установки. Обновление можно установить поверх 0.1.0.

## Установка и одиночная игра

Передайте APK на телефон, откройте и при запросе Android разрешите установку из используемого файлового менеджера. После установки нажмите «Играть одному».

Внутри приложения находятся карта, 60 вопросов, иллюстрации, шрифты и звуки. Интернет и регистрация не нужны. Экспедиция — 12 случайных вопросов: варианты ответа, точка на карте и геодетектив. На вопрос 45 секунд, до 1000 очков за ответ, подсказка стоит 200. Короткие истории сохраняются в дневнике открытий на устройстве.

Категории: страны, города, природа, животные, ресурсы и культура. Это стартовая коллекция по миру, а не полный справочник всех объектов каждой страны. Иллюстрации художественные; карта показывает сушу без административных границ.

## Вместе через точку доступа или Wi-Fi

1. Ведущий сначала включает точку доступа в настройках Android. Остальные подключаются к ней. Альтернатива — общий Wi-Fi-роутер.
2. Все устанавливают одинаковую версию APK.
3. Ведущий нажимает «Создать комнату» и сообщает адрес с портом и шестизначный код.
4. Игроки нажимают «Подключиться», вводят имя, адрес с портом и код.
5. Ведущий запускает экспедицию и переключает вопросы; участники отвечают на своих экранах.

В версии 0.1.1 над вопросом ведущего показаны число ответивших, число ожидаемых ответов и время. Разверните «Статусы участников», чтобы увидеть, кто думает, кто ответил и кто потерял соединение. Ответ отключившегося игрока сохраняется; если он ещё не ответил, его продолжают ждать. После всех ответов появляется «Все ответили!», один раз звучит сигнал (если звук включён) и выделяется кнопка «Показать результаты». Ведущий может раскрыть ответ досрочно; при истечении 45 секунд действует прежнее автоматическое раскрытие.

Ведущий не занимает место отвечающего участника. Сервер допускает до 40 игроков, но фактический предел зависит от телефона/роутера. Для большой группы предпочтителен роутер. Гостевая сеть с изоляцией устройств может блокировать соединение. При нескольких адресах выберите адрес общей сети.

Держите приложение ведущего открытым: выход закрывает комнату. Клиент автоматически пытается восстановить кратковременный разрыв, пока приложение открыто. После перезапуска приложения прежняя сессия не восстанавливается. Игра между разными сетями через интернет в эту версию не входит.

## Проверка и ограничения

27 тестов прошли для 0.1.1, включая статусы ведущего, кнопку результатов, однократный сигнал и отключение звука. Версия 0.1.0 прошла полную партию на эмуляторе без Wi-Fi и мобильной сети, её Android-сервер принял ответы 40 программных клиентов через ADB-туннель. Испытания на 40 физических телефонах ещё не выполнены. Подробнее: `docs/verification.md` и `docs/verification-0.1.1.md`.

Известный небольшой дефект: кнопка «+» карты позволяет увеличить масштаб сверх ограничения жеста. Кнопка сброса возвращает карту в исходное положение.

## Разработка

Flutter 3.19.6 / Dart 3.3.4; SDK 35; Gradle 8.9, AGP 8.7.3, Kotlin 2.0.21. Проверки: `flutter test`, `flutter analyze`. Сборка: `powershell -ExecutionPolicy Bypass -File tools/build-apk.ps1`. Скрипт использует временный ASCII-путь из-за ограничения AOT-сборки старого Flutter в кириллическом пути.

Источники и лицензии: `assets/ATTRIBUTIONS.md`. Генераторы: `tools/make-content.mjs`, `tools/make-audio.mjs`. Публикация в магазине потребует постоянного ключа подписи.
